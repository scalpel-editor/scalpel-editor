# Contributing

## Pull requests

### PR descriptions

Use phrasing and terminology that translates into other languages more easily. Avoid jargon and lots of code symbol references.

### PR scope

Pull requests should be focused on solving one problem or adding one feature.

### AI review

Use a thinking model (set to medium effort or higher) to review your contribution before submitting it. If an agent implemented the code, it's preferred that a different model reviews it.

### Human testing

The human involved should always compile and run the program and manually verify all related functionality works as intended. Edge cases should be considered.
